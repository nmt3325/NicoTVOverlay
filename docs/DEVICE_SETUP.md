# テレビへの導入と自動選局の設定

## 対象と、最初に確認すること

- **テレビ本体のAndroid OSにインストールしてください。** 外付けAndroid TVボックス／スティック上のアプリは、テレビが別入力の内蔵チューナーを表示している間、その画面へ重ね描きできません。
- Android 8.0（API26）以上が対象です。メーカーによっては重ね表示・ユーザー補助の設定が提供されません。
- 一般アプリが他のテレビアプリの「現在局」を得る共通の公開APIはありません。隠しAPI・root・視聴履歴への特権アクセスは使いません。
- 映像・音声の取得、録画、チャンネル操作、コメント投稿は行いません。

## インストールと手動選局

GitHub Actionsの成功した実行の **NicoTVOverlay-debug-…** をダウンロードし、ZIP内のAPKを取り出します。開発用署名付き評価版です。**release-unsignedは未署名**で、そのままインストールできません。

テレビの設定でユーザーが許可したADBから導入する例:

```bash
adb connect <テレビのIPアドレス>:5555
adb install -r app-debug.apk
```

Androidのバージョンによっては無線デバッグのペアリングが先に必要です。実機の開発者向け設定に従ってください。複数デバイスでは`adb -s <デバイス>`を使います。アプリがADBやユーザー補助を自動で有効化することはありません。

1. テレビのアプリ一覧からNicoTVOverlayを開きます。
2. 「他のアプリの上に表示」を許可します。リンクが開かない機種はテレビのシステム設定を確認してください。
3. 通知を許可すると通知にも停止操作が出ます。拒否時は操作画面の停止ボタンを使えます。
4. 手動モードで局を選び、「ニコニコ公式」を選択して開始します。
5. テレビの放送アプリへ戻り、文字が映像上に出るかを確認します。手動モードでテレビの局を変えたときは、アプリ側の局も変更してください。
6. 操作画面／通知の停止で終了します。画面オフでも終了し、起動時には自動再開しません。

通常のアプリ画面で表示できても、内蔵チューナー／HDMI／HDR／DRM映像への重ね表示はメーカーの映像合成方式・制限に依存します。

署名の異なる開発版から入れ替える場合は旧版のアンインストールが必要です（設定が消えます）。mainのCIは同一リポジトリ用の開発署名を使用します。PRの評価ビルドは別署名の場合があります。開発署名は本番公開用の署名とは別物です。

## 局表示からの自動選局: 機種別校正

明示的に許可したテレビアプリの**現在局を表すノード**を端末内で読み取ります。画面全体の録画や他アプリの文章収集はしません。

設定するのは次の項目です。

- **テレビアプリのパッケージ名:** 完全一致。表示名ではありません。
- **局名のリソースID:** 現在の視聴局だけを表す完全修飾ID。
- **ライブ表示のリソースID:** ライブ視聴画面でだけ現れる目印。番組表・検索・録画一覧にも残るノードは不適切です。
- **局名別名（任意）:** 地方局などの完全一致する表示名を実況IDへ対応させるJSON。地方局とキー局の編成が一致するとは限らないため、対応はユーザーが確認してください。

開発者は、ユーザー自身が許可したADBでライブ視聴中のUI階層を確認できます。

```bash
adb shell uiautomator dump /sdcard/nicotv-window.xml
adb pull /sdcard/nicotv-window.xml
adb shell rm /sdcard/nicotv-window.xml
```

XMLにはその時の画面の文字が含まれます。手元で確認し、不要なファイルは削除してください。局A・局B・番組表・録画一覧を比較し、局名とライブ専用のノードを識別します。XMLに現在局が出ないテレビでは、この方式は利用できません。

IDは`実際のパッケージ:id/実際のリソース名`の形です。説明用の名前をそのまま入力しても動作しません。設定欄はカンマ／改行区切りです。別名JSONの形式:

```json
{"ユーザーが確認した表示局名": "jk4"}
```

プロフィールを保存し、テレビのユーザー補助設定で局検出サービスを有効にしてから自動モードを開始します。サイドロードでは「制限付き設定」の追加許可が必要な場合があります。

**校正後に確認する操作:** 素早いA→B→C選局、番組表、録画再生、Home、別アプリ、画面オフ。誤った局を維持するプロフィールは使わないでください。

曖昧・未対応・古い局情報は旧コメントを消します。最後の局の証拠の有効期限は30秒です。数秒だけ出る局表示しか読めない機種では常時追従にはなりません。手動固定と自動判定は区別します。

## BRAVIA LAN連携: 実験的

対応機種のIPコントロールを設定し、同じLANのテレビの**数値のプライベートIPv4アドレス**とユーザー設定のPSKを入力します。自動探索、電源・入力の変更は行いません。

使用メソッドはSonyの`getPlayingContentInfo`です。局フィールドは機種で異なるため、返される放送URIと実況IDの対応を明示設定します。HDMIの名前や番組タイトルだけで局を推測しません。現在局・入力・アプリ切替時の応答を実機で確認してください。

このLAN通信は機種のHTTP APIを使うため暗号化されません。信頼できるLANでのみ有効にし、PSKを他の用途へ流用しないでください。ニコニコ／NXへの通信はHTTPS・WSSです。

## 接続元・時差・困ったとき

- **ニコニコ公式:** 公式実況に対応する現在の生放送からコメントだけを受信します。
- **NX-Jikkyo:** 明示選択する別サービス。公式ミラーと独自投稿が混ざる場合があり、公式直結とは区別します。公式の不調で自動切替しません。
- **デモ:** 操作画面内の合成コメント。通信せず、受信成功の証拠には使いません。

放送経路・地方局には時差があります。コメントが先行する場合は遅延設定で調整します。既に遅れて届くコメントを未来へ先回りして表示することはできません。

- 権限設定が存在しない／許可できない: メーカーの仕様です。その方式は利用できません。
- 局未検出: パッケージ・局名ID・ライブ専用ID・別名・有効期限を確認します。
- 接続待ち／放送なし: インターネット、端末日時、公式ポータルの現在の放送を確認します。
- 操作画面のデモは見えるが放送上では見えない: メーカーの映像合成方式による制限の可能性があります。

参考: [公式実況](https://site.nicovideo.jp/jk/)、[Android TV SDK](https://developer.android.com/reference/android/media/tv/TvInputManager)、[Sony REST API](https://pro-bravia.sony.net/remote-display-control/rest-api/reference/)。
