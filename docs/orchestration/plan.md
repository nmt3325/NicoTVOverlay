# Parallel implementation contract

Goal: sideloadable Kotlin Android TV (min26 target35) live Jikkyo overlay. Official NicoNico is default. NCOverlay is a design reference; do not confuse VoD/archive with live transport.

Ownership: parent owns root Gradle/CI, core, app, integration, main push. Child comment owns comment-client/src/** and docs/research/comment-api.md. Child detection owns detection/src/** and docs/research/station-detection.md. Child overlay owns overlay/src/** and docs/research/rendering.md. Investigators/reviewers write assigned external reports only. Shared contracts are core/src/main/kotlin/dev/nicotv/core/{Contracts,StationCatalog}.kt and this plan, parent-only.

Public interfaces (implement without changing core):
- dev.nicotv.comment.NicoLiveCommentSource(client: okhttp3.OkHttpClient = OkHttpClient()) : CommentSource
- dev.nicotv.comment.NxJikkyoCommentSource(client: okhttp3.OkHttpClient = OkHttpClient()) : CommentSource
- Cold Flow<StreamEvent>; cancellation closes all socket/body/timer resources. Official errors explicit; NX only separately selected, provenance labeled.
- dev.nicotv.detection.StationDetectionBus.observation: StateFlow<StationObservation>, unknown initially; publish(observation) for in-process updates.
- dev.nicotv.detection.NicoTvAccessibilityService : AccessibilityService. PreferenceContract.STORE, DETECTION_MODE only MODE_ACCESSIBILITY permits observation. TV_PACKAGES comma/newline list; defaults DEFAULT_TV_PACKAGES. CUSTOM_ALIASES JSON object exact local label to jk ID.
- dev.nicotv.detection.BraviaStationDetector(client: okhttp3.OkHttpClient = OkHttpClient()).observations(host: String, psk: String): Flow<StationObservation>. Optional explicit LAN configuration only.
- dev.nicotv.overlay.DanmakuView(context: Context, attrs: AttributeSet? = null) : View. addComment(comment: LiveComment), updatePreferences(preferences: OverlayPreferences), clearComments(). Own monotonic clock, bounded delay queue, animation lifecycle.

Tests: deterministic synthetic fixtures, module-focused tests with logs and exit codes. At most ONE Gradle process at a time: use flock on parent-specified external gradle.lock. Outputs stay in each worktree. Shared Gradle artifact cache may lock. Parent reruns complete test/lint/debug/release gates after sequential merges, then independent reviewer checks. Network smoke distinct from unit tests.

Children may commit own branch only; no push, common config changes, worktree manipulation, other process stopping, environment lifecycle, credential output or undelegated grandchildren. Block/report if contract change needed. Report status, base/head SHA, changed files, checks incl command_id/exit/eof/logs. Parent owns integration and publishes validated milestones to main.

Product: automatic station reading is device/app dependent, never guaranteed universally. No guessing from remote key number or EPG full station list. Unknown/ambiguous/non-TV observations clear selection. Opt-in accessibility and overlay, optional BRAVIA network access. User-started foreground specialUse with notification Stop. No boot autostart, hidden capture, raw text retention or credentials in logs. Manual and DEMO modes visibly distinct. Private technical repository: no personal workspace content or execution identifiers in git.

## Research decisions and final allocation
- Official anonymous live receive was verified: watch/ch embedded-data → watch WS startWatching(reconnect=false) → messageServer.viewUri → HTTP varint-delimited NDGR ChunkedEntry/ChunkedMessage. First at=now may return only next.at + normal EOF; continue cursor. Protobuf source n-air-app/nicolive-comment-protobuf commit 2e852e08df016888aefa602ec6c5be6a558eb3d9. Maintain seat/pong and bounded reconnect. Read parent-provided survey before implementation.
- Four independent implementation worktrees: comment, detection, overlay, app. Parent now retains root config/core/review/integration/docs; APP CHILD exclusively owns app/src/** and docs/research/app-lifecycle.md. Each module includes compile-only public placeholders so independent focused builds work; replace/remove ALL placeholders before final delivery.
- Detection requires PreferenceContract.SESSION_ACTIVE=true AND explicitly selected mode. Application resets this volatile authorization false on fresh process startup; user-started FGS owns true/false. Accessibility connected alone must not collect.
- PreferenceContract.OSD_RESOURCE_IDS: comma/newline exact fully-qualified station-label resource IDs. LIVE_RESOURCE_IDS: comma/newline exact live-player marker IDs. Both empty by default; user configures a device profile. No automatic guessing of all-app text. A live marker and exactly one station are required. EPG/list/recording/ambiguous → Unknown. Timestamp observedAtMs uses SystemClock.elapsedRealtime (monotonic); 30s evidence TTL, 750ms re-read debounce; foreground heartbeat does NOT renew evidence age.
- BraviaStationDetector(client=OkHttpClient(), channelMap: Map<String,String> = emptyMap()) supports explicit URI→jk mapping. PreferenceContract.BRAVIA_CHANNEL_MAP is a JSON object for that mapping, passed by app. Documented method getPlayingContentInfo (not getPlayingContent); source must start tv:, no HDMI/title-only guessing. Experimental until model validation. Numeric RFC1918 IPv4 host only; redirects disabled, tight deadlines, bounded response, no automatic LAN scan, no PSK in logs. Host/PSK supplied only by settings and request only after Start. HTTP exception may be enabled at app level for this explicitly configured adapter but every comment URL MUST remain HTTPS/WSS with validated service hosts; document the local cleartext transport. Store PSK encrypted with AndroidKeyStore in app, not plain preferences/export.
- Application: TV remote-friendly Japanese UI, live state/provenance, permissions/Start/Stop/manual channel cards, explicit backend selection (official default, NX separate), font/opacity/speed/delay/NG controls, advanced package/OSD/live marker/custom alias/BRAVIA configuration. Visibly labeled offline DEMO preview is separate and never used as a live fallback. SpecialUse FGS, nonfocusable+nontouchable single overlay, LayoutParams.alpha at most platform obscuring limit (normally0.8), screen-off Stop, START_NOT_STICKY, no boot start. Latest-generation-only comments and renderer clear on station/mode changes. Missing permissions/settings activities handled gracefully.
- Automated emulator fixture may exercise station switching, but never describe fixture UI as real tuner/OEM verification. No raw real comments/URL tokens in evidence or git. No production signing keys in repository; CI debug APK versus unsigned release APK clearly distinguished.
